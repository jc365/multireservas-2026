# Sistema de Diseño - Slate Casting

## Guía de Estilo
La guía de estilo completa está definida en `frontend/design/DESIGN.md`. Contiene la paleta de colores, tipografía, espaciado y componentes.

## Maquetas HTML
Las maquetas exactas de las páginas generadas por Stitch están en la carpeta `frontend/design/`:
- **Dashboard:** `frontend/design/dashboard.html`
- **Detalle de Casting:** `frontend/design/casting-detail.html`
- **Detalle de Ronda:** `frontend/design/round-detail.html`

Estas maquetas son la referencia visual exacta. Debes replicar su estructura, distribución y componentes al generar las páginas de React.

**Instrucción:** Al generar cualquier página del frontend, consulta primero el `DESIGN.md` para los estilos y la maqueta HTML correspondiente para la estructura y el layout.
